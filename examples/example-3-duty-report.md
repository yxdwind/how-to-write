# 案例 3：写一份自己的述职报告

> 场景标签：述职报告 · 三属性 · 三胜
> 涉及章节：ch09（述职报告的写法）

## 场景

年底述职，要求"10 分钟述职+民主测评打分"。你的初稿是一份流水账："一月开了什么会、三月干了什么项目"——自己读着都平。本书第九讲的三胜法（以实、以数、以事和绩取胜）专治这个。

## 你怎么说

> 年底述职，初稿附后（流水账版）。用怎样写作的述职报告方法帮我重构：先校准三属性，再用"以实取胜、以数取胜、以事和绩取胜"重写，10 分钟口播版，别让我写成记事本。

## AI 执行路径

1. 读 `chapters/ch09-duty-report-writing.md`（三属性定调、三胜法、反面模式）
2. 三属性校准：职务职责（述的什么岗）、个人个体（哪些是你的独立贡献）、上报下知（对上汇报+对下测评）
3. 从流水账中挖"大实"：把琐事升级为体现全局价值的事
4. 数据盘活：把"死数据"（做过什么）转成"活数据"（同比/环比/首次/大关）

## 方法论如何落地

- **以实取胜**：报告只有自己写才能写实；理论学习部分不写空——写"怎样把某理论用到某决策上"
- **以数取胜**：每部分有数据；"处理工单 400 件"是死数据，"平均响应从 8 小时压到 90 分钟，投诉率环比降 41%"是活数据
- **以事和绩取胜**：浓墨重彩写透两三件大事（根据什么干的、怎么干的、干出什么、还有什么问题）；政绩所有权干净——团队业绩注明"我主导/我参与"
- **开头十二个字**："根据有关要求，现作如下述职"——不铺帽子

## 关键输出片段（模拟）

```markdown
重构对照（流水账 → 三胜版）：

流水账原句："3 月组织了系统迁移项目。"
三胜版："主导核心系统迁移（全组 4 人参与，我负责方案与切换预案）：
零中断完成，故障率同比下降 100%——这是近三年首次大版本零事故。
遗留：灰度覆盖仅 60%，下季度补齐。"
（根据什么干→怎么干→干出什么→还有什么问题）

开头："根据有关要求，现作如下述职。"（12 字，不铺帽子）

自检：每部分有活数据 ✓ 两件大事写透 ✓
政绩所有权标注 ✓ 无"记得领导关怀"式空话 ✓
```

## 书中依据

- 述职三属性：职务职责、个人个体、上报下知（ch09）
- "实要有高度和深度——大实不是记事本式的小实"（ch09）
- "开头只用十二个字，避免帽子太大"（ch09）
- "轻描淡写十件小事，不如浓墨重彩两三件大事"（ch09）
