## 填卡三原则

1. **原文全文粘贴**——只贴骨架等于没贴：口吻学自原句，不是学自概括。本目录不入仓库，无版权顾虑；涉密数据自行脱敏。
2. **填空即过筛**——每个模板的自查清单与对应 rubric 同构，填卡过程就是一次人工过筛；填不出来的格子（如"量化标识举例"空着）说明范文本身不达标，换一篇。
3. **一范文一卡，宁精勿滥**——一篇真范文配一份完整拆解，胜过十篇只有标题的收藏。格子里"可复用点/禁忌"是给未来起草时的你写的，写具体。

## 优先级规则（models/README.md 同款）

起草同类文体时：`local/` 真实范文卡 **优先于** 内置卡。Agent 侧约定：models/ 目录下先找 local/ 有无匹配卡，有则先读。
