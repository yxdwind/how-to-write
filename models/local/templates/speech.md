# 领导讲话稿 · 本地范文填空模板

> 用法：拿到真实讲话稿后复制本文件重命名（如 `王局年度工作会讲话.md`），按 【】 提示填空。
> 填完后这张卡就是 `models/local/` 的正式范文卡，起草同类稿时优先于内置卡被读取。
> 检查项与 rubrics/speech.md 对齐——填的过程就是按筛过一遍。

## 一、原文粘贴区

【把范文全文粘贴到这里。只放本地自用，此目录不入仓库，无版权顾虑。】

## 二、拆解卡（填空）

### 基本信息
- 场景：【什么会、什么场合、多少人】
- 讲话人：【职务、层级；讲话风格特点（如务实/爱举例/有口头禅）】
- 时长与字数：【实讲约 __ 分钟 / 全文约 __ 字；折算语速约 __ 字/分钟】

### 骨架（块结构）
- 开头：【一句话概括入题方式；几行入题】
- 主体块：【块1标题 → 讲了什么】【块2标题 → 讲了什么】【块3…】
- 结尾：【如何收口；落在什么上】

### 文风特征（至少 3 条）
1. 【如：短句为主，最长句 __ 字】
2. 【如：部署部分全部带量化（例子：____）】
3. 【如：口语标记（例子："____"）】

### 数据位
- 【原文中的量化标识举例：项目数/户数/时限/比例——抄 3–5 个】

### 金句/实在话
- 【抄 1–3 句最有"这个讲话人味道"的句子】

### 可复用点
- 【什么时候可以套这张卡：场景、听众、文体任一相近即可】
- 【套用禁忌：哪些内容必须换（如数据全部换、案例必须新）】

## 三、自查（对照 rubrics/speech.md）

- [ ] S1 三个吃透：稿中能看出情况/上级精神/讲话人意图的结合
- [ ] S2 时长：字数与实讲时长匹配（150–200 字/分钟）
- [ ] S3 五度：实度深度高度新鲜度气势，各举一处原文证据
- [ ] S4 稿中有数：量化标识充分
- [ ] S5 口吻对对象：称呼/口气/场合感
- [ ] S6 宜短不宜长：无凑体量的段落
