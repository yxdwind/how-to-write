# 随笔/杂文 · 本地范文填空模板

> 用法：复制本文件重命名（如 `篮球随笔拆解.md`），按 【】 填空。填完即成 local 正式卡。
> 检查项与 rubrics/essay-selfmedia.md 随笔节对齐。

## 一、原文粘贴区

【范文全文。若非本人作品，只放本地自用（本目录不入仓库）。】

## 二、拆解卡（填空）

### 基本信息
- 类型：【故事型随笔/喻理型杂文/先发制人型杂文/其他】
- 题材与切入：【写什么事/什么物；小切口是什么】

### 骨架
- 故事—情怀—哲理循环：【故事1 → 情怀/感想 → 哲理（用了几段议论）→ 再故事 → 收尾】
- 杂文对应表：【物的特征 → 对应的人理，逐对列出；末句如何扣题】

### 哲理与议论比
- 哲理句举例：【抄 1–3 句；长在故事里还是悬在空中】
- 议论占比估计：【约 __ 成（红线：不超过三成）】

### 真实性来源
- 【细节来自什么真实经历；哪些数字/对话/场景让细节"编不出来"】

### 可复用点
- 【什么题材可套这个循环；禁忌（无真实经历不写）】

## 三、自查（对照 rubrics/essay-selfmedia.md 随笔节）

- [ ] E1 六字真言：真（无编造）情智善理美
- [ ] E2 三有：料（有细节）趣（有兴味）度（有分寸）
- [ ] E3 哲理长在故事里：议论 ≤ 三成
- [ ] E4（杂文）末句扣题
- [ ] E5（杂文）讽刺善意理智
