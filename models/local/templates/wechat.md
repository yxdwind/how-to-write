# 自媒体/公众号文 · 本地范文填空模板

> 用法：复制本文件重命名（如 `对标账号-退款潮爆款拆解.md`），按 【】 填空。填完即成 local 正式卡。
> 建议优先拆你对标账号的真实爆款。检查项与 rubrics/essay-selfmedia.md 自媒体节对齐。

## 一、原文粘贴区

【爆款全文 + 基础数据（阅读/在看/转发，若可得）。只放本地自用。】

## 二、拆解卡（填空）

### 基本信息
- 账号与赛道：【哪个号、什么领域；粉丝画像】
- 篇幅与结构密度：【__ 字；几段；段落节奏（长段/短段/一句段）】

### 骨架与钩子
- 开篇钩子类型：【幽灵式（具体+反常）/ 分合式（宏大浓缩）/ 安娜式（对照断言）/ 其他——抄出原句】
- 主体推进：【块1 → 块2 → …；靠什么推进（故事/数据/逻辑链/情绪）】
- 悖理翻转位：【抄出"看似悖理的一句话"+作者是怎么用论证接住的】
- 金句位：【抄出全部金句；数一数共几处（1–3 为健康）；绿叶铺垫够吗】

### 标题
- 标题原文：【__ 字】
- 吸引力与贴切：【张力点是什么；正文接得住吗（题不对文检查）】

### 数据/案例来源
- 【文中数据来自哪里（公开报告/访谈/作者亲历）；有无明显编造感】

### 可复用点
- 【什么选题可套这个骨架；我们账号能学的 1–3 点；不能学的（人设不同）】

## 三、自查（对照 rubrics/essay-selfmedia.md 自媒体节）

- [ ] M1 标题吸引力+贴切双达标
- [ ] M2 开篇 3 行有钩子
- [ ] M3 有悖理翻转且论证接住
- [ ] M4 短快真实新：可删的全删过；无编造；有增量
- [ ] M5 金句 1–3 句、有绿叶铺垫
- [ ] M6 平台适配（字数/分段/口吻）
