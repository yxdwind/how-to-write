# 规范性公文 · 本地范文填空模板

> 用法：复制本文件重命名（如 `区局汛期排查通知.md`），按 【】 填空。填完即成 local 正式卡。
> 检查项与 rubrics/official.md 对齐。

## 一、原文粘贴区

【范文全文。本地自用。】

## 二、拆解卡（填空）

### 基本信息
- 文种：【决议/意见/通知/报告/请示/批复/函/纪要】
- 发文机关与行文对象：【谁发给谁；上行/下行/平行】
- 背景：【为什么发这份文；解决什么问题】

### 骨架
- 首段：【依据 + 决定/要义如何开宗明义】
- 主体条目：【一、___（查什么/做什么）】【二、___（谁负责）】【三、___（何时报）】
- 结尾：【执行要求/施行日期/联系人】

### 量化与时限（公文的心脏）
- 【抄出原文所有量化标识：个数/百分比/页数/日期，逐条列】

### 措辞特征
- 商量口气出现吗：【无 / 哪里留了"一般"的余地】
- 意义认识段：【有无？"略写或不写"执行得如何】
- 时间精确度：【写到日还是月】

### 可复用点
- 【什么文种、什么场景可套】
- 【禁忌：哪些内容必须换（单位/依据文号/数据）】

## 三、自查（对照 rubrics/official.md）

- [ ] G1 政策衔接：引用的上位文件名/文号齐全
- [ ] G2 权威性：无商量口气（"一般"仅用于正当留余地）
- [ ] G3 可操作性：要求带量化/时限/责任主体
- [ ] G4 骨架对位：与文种匹配
- [ ] G5 时间写到日
- [ ] G6（通知类）不写意义不谈认识
- [ ] G7（纪要类）归堆瘦身，不是会议记录
- [ ] G8（问题性报告）有解决办法，无"矛盾上缴"
