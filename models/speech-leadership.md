# 范文拆解卡：领导讲话稿（speech-leadership）

> 素材来源：《怎样写作》第七讲原书实例。本卡是拆解，不是原文；起草前通读本卡 + ch07。
> 体积小是特点不是缺点：原书主张「宜短不宜长」——即席 15 分钟、一般会议 25 分钟、年度主报告一个半小时足够。

## 卡 1｜《临别赠言》——对普通受众的送别讲话

| 维度 | 拆解 |
|------|------|
| 场景 | 老石给 700 多名赴珠三角打工青年送行 |
| 骨架 | 两代人对比点出时代背景 → 三句话主体（把困难想得多一些 / 用心学习真本事 / 努力改变自己适应环境）→ 收束期望 |
| 文风 | 平实简短有深意、暖意融融；通篇像拉家常——**对普通受众用群众语言说事明理，深奥道理和生僻术语等于白讲** |
| 结构诀 | 三条主线各管一件事，互不交叉；每条一句话立骨，展开不过三五行 |
| 可复用 | 对非专业受众：砍术语、砍排比，用对方生活里的例子讲道理 |

## 卡 2｜全省农村工作会议讲话——大型工作会议主报告

| 维度 | 拆解 |
|------|------|
| 场景 | 全省农村工作会议，年度工作主报告 |
| 骨架 | 成绩（四个破折号概括"生产、生活、建设、组织"）→ 归因（五个得益于）→ 形势（有利因素只一行半，重点摆困难但不泄劲，落点"勇闯困难期"）→ 部署（十点意见） |
| 文风 | 七分实：成绩不铺排，形势不回避矛盾；部署部分项目、面积、时间全部量化（水利工程均有量化标识） |
| 结构诀 | 成绩段做减法、困难段做加法——**"形势分析只一行半讲有利因素"是详略服从主题的样板**；讲业务问题既讲业务又扣生产关系（业务背后站着立场） |
| 可复用 | 年度主报告通用骨架：成绩→归因→形势→部署；量化标识写进部署条目（项目/面积/时间） |

## 两卡合成示范（原书无此稿，按原书标准写就，供模仿口径用）

> 场景：某县防汛工作紧急会议，局长讲话，10 分钟（约 1500 字）。
> **【示范稿】**——注意七分实、短句、部署带量化，这三点是 ch07 的灵魂：

```
同志们：

  县里决定今天把大家请来，只讲一件事：防汛。明天起全县进入主汛期，
气象部门的判断是雨情偏重，咱们不跟天气赌运气。

  先说形势。入汛以来全县平均降雨比常年多三成（来源：县气象局 6 月简报），
三座小二型水库水位都已超限，这是当前最要紧的家底。就说最紧的 X 水库：
抢险队 30 人今天到位，编织袋 2 万条已入库——还不够，缺的部分明天中午前补齐。

  再讲三句话。第一，责任到人：每座水库、每段堤防名单今天下班前报我，
一张表管到底，谁的名字谁负责。第二，值班到岗：汛期 24 小时双人值班，
查岗查到人，脱岗一次通报一次。第三，准备到物：各乡镇明天上午 10 点前
把物资台账报上来，缺什么报什么，不许报"已备齐"三个字应付。

  最后一句：防汛不怕情况紧，就怕心里没数。大家把数摸清、把人盯住，
安全度过主汛期，到时我给大家请功。

  就讲这些。
```

**示范稿拆解**（自己对照）：开头一句话入题（场合感）；形势段有数据且注明来源、点出"最紧的家底"；三句话主体各管一件事（责任/值班/物资，全部量化到点到位时间）；结尾短而有力落在愿景。全文无排比铺陈、无"高度重视"空转——这就是实度与短。

## 使用规则

1. 起草前：本卡 + ch07 + rubrics/speech.md（自检在交付前）。
2. 模仿的是**骨架与口径**，不是句子；换场景必须换例证。
3. 有更贴近的真实范文时，放 `models/local/`（不入仓库），起草前优先读本地卡。
