# 范文拆解卡：随笔与杂文（essay）

> 素材来源：《怎样写作》第十一讲原书实例。本卡是拆解，不是原文；起草前通读本卡 + ch11。
> 一句话心法：**六字真言"真情智善理美"，哲理长在故事里**——议论多了会说教。

## 卡 1｜《充满激情和哲理的篮球》——故事型随笔

| 维度 | 拆解 |
|------|------|
| 骨架 | 故事（"小9号"雪地练球、鞋底磨出血用硬纸壳"鞋底再造"）→ 情怀（下乡抬篮球架，"不是为了锻炼身体，完全是为了释放青春的激情"）→ 哲理（三个"不重要/重要"、五个"你"）→ 再故事（球场识人）→ 直抒胸臆（"篮球真好！"） |
| 文风 | 细节全部来自 50 余年亲历——"这种事编也编不出来"；结尾率真 |
| 结构诀 | **故事—情怀—哲理—再故事**循环：议论多了立即切回故事 |
| 可复用 | 个人经历类随笔万能骨架；无真实经历不写（六字真言第一字就是"真"） |

## 卡 2｜《小麦的两种状态》——喻理型杂文

| 维度 | 拆解 |
|------|------|
| 骨架 | 通篇写物少写人（灌浆时"青涩泛绿、身段欠坚"，成熟时"通身金黄、腰杆硬朗"）→ 对应着写 → 末句扣题（"小麦与人息息相通"） |
| 文风 | "傲慢流露的是七分浮躁，谦和蕴涵的是九成厚实"——金句在段中自然长出 |
| 结构诀 | **以小喻人、对应着写、末句扣题**：物的每个特征对应一层人理 |
| 可复用 | 针砭时弊但不点名的讽喻文；讽刺善意理智留余地 |

## 卡 3｜《自我感觉不宜太好》——先发制人型杂文

| 维度 | 拆解 |
|------|------|
| 骨架 | 首段先发制人（观点亮牌）→ 中段一个完整反面典型小故事（民主生活会上"多年自我感觉良好，真没想到还有这么多坏毛病"）→ 末段点破危害（"乱决策、瞎指挥常与自我感觉良好画等号"） |
| 结构诀 | **亮牌→故事→点破**三段式；讲一个故事胜过发十句议论 |
| 可复用 | 职场/世相评论短文；故事必须是真事或标明虚构 |

## 六字真言 × 三有五可 速查

| 维度 | 落地自检 | 出处 |
|------|---------|------|
| 真 | 素材是亲历/真实见闻吗？假的、编的、无感的不写 | ch11 |
| 情 | 有没有情感的浓度（不是煽情的堆砌）？ | ch11 |
| 智 | 有没有超出常识的一点洞见？ | ch11 |
| 善 | 讽刺是否善意理智、对事不对人？ | ch11 |
| 理 | 哲理是否长在故事里（议论≤三成）？ | ch11 |
| 美 | 语言是否干净有味（不堆辞藻）？ | ch11 |
| 三有 | 料（有细节）趣（有兴味）度（有分寸）一并具备 | ch11 |
| 五可 | 可追素雅/可舒情怀/可发感慨/可阐事理/可明志向——任取一二即可 | ch11 |

## 合成示范（原书无此稿，按原书标准写就，供模仿口径用）

> 场景：个人公众号随笔，约 800 字，写"搬家"这件小事里的哲理。素材假设为作者真实经历。
> **【示范稿】**——注意故事开篇、哲理节用、末句扣题：

```
最后一次搬家

  搬家师傅老周把我的书装了整整十四箱。他擦着汗说：
"姑娘，搬了二十年家，书多的都是好人家。"

  十四箱书里，有二十本从没拆过塑封。搬家前一晚我坐在
纸箱中间一本本翻，翻到那本在大城市书店排了两小时队买的
随笔集——扉页上写着当年的日期，五年了，一页没读过。

  我把它们一本本拆开塑封，又一本本放回纸箱。老周在旁边
看不懂：这不还是搬走吗？
  是的，还是搬走。但我得让它们以"读过的书"的身份搬走，
而不是以"收藏品"的身份。

  我们总以为拥有是一个动作——买下它、带走它、摆上架子。
其实拥有是两个动作：把它带回来，再把它带进身体里。
中间那一半，大多数人一辈子都没做。

  车开动了。十四箱书在后视镜里越来越小，像十四个
终于被兑现的承诺。

  书如此。人大概也如此。
```

**示范稿拆解**（自己对照）：开篇即故事（师傅一句话带出人物）；细节真实可感（十四箱、二十本塑封、两小时排队）——"编也编不出来"的质感来自具体数字；哲理只在第五段出现一次（"拥有是两个动作"），前后全是故事与画面；议论约占两成，未超三成红线；末句扣题（书→人），点到即止。

## 使用规则

1. 起草前：本卡 + ch11 + rubrics/essay-selfmedia.md（随笔节）。
2. 随笔的命是"真"：AI 起草前必须向用户要到 2–3 个真实细节（数字、对话、场景），要不到就退回——**禁止编造经历**。
3. 杂文讽刺守"善意理智"底线：对事不对人，末句留余地。
