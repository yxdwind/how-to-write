# 范文拆解卡：自媒体/公众号文（wechat-article）

> 素材来源：《怎样写作》第十一讲原书实例与框架。本卡是拆解，不是原文；起草前通读本卡 + ch11。
> 一句话心法：**短快真实新，短摆第一位；金句是红花，绿叶铺垫不可少。**

## 卡 1｜《充满激情和哲理的篮球》——故事型随笔（公众号情感/成长类骨架）

| 维度 | 拆解 |
|------|------|
| 骨架 | 故事（少年"小9号"雪地练球、鞋底磨出血用硬纸壳"鞋底再造"）→ 情怀（下乡抬篮球架，"不是为了锻炼身体，完全是为了释放青春的激情"）→ 哲理（三个"不重要/重要"、五个"你"——集体、纪律、规矩）→ 再故事（球场识人）→ 直抒胸臆收尾（"篮球真好！"） |
| 文风 | 全部细节来自 50 余年亲历——"这种事编也编不出来"；哲理节用排比但短；结尾一句率真收口 |
| 结构诀 | **故事—情怀—哲理—再故事**循环：议论多了会说教，及时切回故事——哲理长在经历里，不悬在空中 |
| 可复用 | 个人成长号、品牌故事文的万能骨架；素材必须真实亲历，没有就换素材，不编 |

## 卡 2｜《小麦的两种状态》——喻理型杂文（观点号/洞察类骨架）

| 维度 | 拆解 |
|------|------|
| 骨架 | 首段先发制人（观点亮牌）→ 通篇写物少写人（灌浆时"青涩泛绿、身段欠坚"，成熟时"通身金黄、腰杆硬朗"）→ 对应着写（物的每个特征都有一层人理）→ 末句扣题（"小麦与人息息相通"） |
| 文风 | "傲慢流露的是七分浮躁，谦和蕴涵的是九成厚实"——金句在段中自然长出，不硬造 |
| 结构诀 | **以小喻人、对应着写、末句扣题**：选一个直观可感的物/现象，每个物性对应一层人性 |
| 可复用 | 洞察类爆文骨架：热点/日常现象 → 逐层对应 → 收一句人生/商业判断 |

## 卡 3｜自媒体五要的落地参数（ch11 框架）

| 要 | 落地动作 | 合格线 |
|----|---------|--------|
| 吸引力标题 | 生动第一、贴切兜底；10 字左右居多 | 题不对文=死穴 |
| 开篇决定性 | 前 3 行一个钩子；三句经典开篇范式：幽灵式（意象悬念）/ 分合式（宏大浓缩）/ 安娜式（对照断言） | "随着…的发展"式起手即败 |
| 盯热点痛点穴位 | 在痛点写一句似乎悖理的话，再颠覆或换维度解析 | 趣味和新意从翻转来 |
| 短快真实新 | 短第一：写完删一遍，可删的全删；真实：无编造；新：有增量信息或新角度 | 每篇洋洋万言即违背短字诀 |
| 淘金句 | 全篇 1–3 句可摘转的主旨句，段首/段中/段尾皆可 | 金句需十几句绿叶铺垫；金句轰炸=以文害义 |

## 合成示范（原书无此稿，按原书标准写就，供模仿口径用）

> 场景：公众号观点文，约 900 字，标题+开篇+一个反转+金句收束。
> **【示范稿】**——注意开篇钩子、悖理翻转、金句密度（全文只两句）：

```
标题：会写周报的人，正在被周报拖垮

  我们公司裁掉了一个每天花两小时写周报的员工。（幽灵式开篇：具体+反常）

  不是因为他写得多。恰恰相反，领导原话："周报写得最好，活干得最糊。"
  他的周报里，三成是 hours（工时拆解），三成是形容词，剩下四成
  在解释上周为什么没干完。真正的事，一条装不下。

  你可能会说：那是他活不行，关周报什么事？
  关系大了。周报的坑在于：它奖励"看起来干了"，不奖励"干成了"。
  一个人的精力是定量的，花在"描述工作"上的每一分钟，
 都是从"完成工作"里扣的。

  真正的高手怎么写周报？三行。
  第一行：本周推进了什么，一句话。
  第二行：卡在哪，需要谁拍板。
  第三行：下周交什么，具体到日期。
  写不出来？说明你这一周本来就没干成事——周报只是把这话说出来了。

  周报是工具，不是作品。（金句一，绿叶铺垫后自然出现）
  别让汇报的形式感，吃掉你做事的完成感。（金句二，收束）
```

**示范稿拆解**（自己对照）：标题吸引力+贴切（"被拖垮"有张力，正文真能接住——不题不对文）；开篇幽灵式钩子（具体的人+反常的事，3 行内完成）；"奖励看起来干了，不奖励干成了"是痛点处的悖理翻转；全文 900 字、7 段（短字诀）；金句只出现在结尾两联，前面全是绿叶。无编造细节（裁人案例为示例场景，套用时必须换成用户真实素材）。

## 使用规则

1. 起草前：本卡 + ch11 + rubrics/essay-selfmedia.md。
2. 平台适配：公众号可用本卡骨架；小红书改为「标题强钩 + 3–5 行短段落 + 每段一个钩子 + 标签」——短第一。
3. 三个经典开篇范式是"形"，真实素材是"魂"：没有真实经历/案例就向用户要，禁止编造故事。
4. 有对标账号的爆款文时，放 `models/local/`（连同一条拆解：钩子类型/结构/金句位），起草前优先读。
